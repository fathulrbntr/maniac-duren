# Patch 024 — Ukuran kartu karyawan

Terapkan setelah patch 023. Timpa file sesuai folder, lalu Ctrl+F5. Tidak perlu SQL.

Semua kartu memakai tinggi tetap (300px desktop, 280px mobile). Nama panjang mengecil otomatis sesuai ruang saat kartu berubah ukuran dan setelah font dimuat. Username dan role memakai ellipsis jika terlalu panjang. Menu titik tiga berada di bawah status aktif/nonaktif.

Validasi: pemeriksaan sintaks serta tes DOM interaksi kartu dan formulir akun berhasil. Tampilan belum diverifikasi melalui browser visual.
