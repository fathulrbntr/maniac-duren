# Database

pos.sql: instalasi baru, hasil npm run db:build.
upgrade.sql: pembaruan database aktif versi 024.
clear-operations.sql: reset data operasional, mempertahankan karyawan dan aksesnya.
sections/: sumber SQL dan validasi upgrade; tetap diperlukan untuk build/test.
audit-data.sql: pemeriksaan integritas tanpa reset.
