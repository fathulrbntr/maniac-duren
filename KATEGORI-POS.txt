MANIAC DUREN — PATCH 051: SIMPAN KATEGORI DAN PESAN ERROR

Paket perubahan di atas patch 050. Berisi file baru/berubah saja.

LANGKAH PEMASANGAN
1. Ekstrak dan timpa file proyek dengan isi ZIP ini.
2. Di Supabase → SQL Editor, buka query baru. Salin SELURUH isi file
   database/pos-menu-categories.sql lalu klik Run.
   SQL ini menyamakan fungsi simpan/baca kategori dengan web sekarang.
   Dapat dijalankan ulang bila kategori versi 047 sudah terpasang.
   Tidak perlu menjalankan pos.sql atau mereset database.
3. Commit dan push perubahan web, tunggu deploy selesai, kemudian muat
   ulang POS dengan Ctrl+Shift+R.
4. Buka Kelola kategori, pilih produk, lalu Keluarkan yang dipilih.
   Produk tetap ada di Semua dan data stok/master tetap tersimpan.

TEMUAN
Web publik sudah memuat app.js dan CSS patch 050 pada pemeriksaan ini.
Pesan "Perubahan kategori belum terkonfirmasi" adalah pesan umum, bukan
pesan asli Supabase. Sebelumnya pesan asli hanya diteruskan ke notifikasi
halaman, yang tertutup oleh pop-up dialog.

Database kategori versi 046 memakai format simpan berbeda. Dalam pengujian
lokal, payload web baru ditolak dengan "Pilihan produk tidak valid atau
terlalu banyak" sampai SQL kategori diperbarui. Ini adalah kasus yang
terverifikasi pada database uji; versi fungsi yang aktif di Supabase pengguna
belum dapat diperiksa langsung.

PERBAIKAN
- Pop-up sekarang menampilkan pesan kesalahan server yang sebenarnya,
  termasuk konflik versi, hak akses, fungsi belum terpasang, koneksi gagal,
  dan pengiriman sebelumnya yang belum pasti.
- Bila fungsi/tabel kategori belum ditemukan, ada petunjuk menjalankan SQL.
- Pilihan centang tetap ada ketika gagal. Tidak ditampilkan status sukses
  bila server menolak penyimpanan.
- Kirim ulang tetap menggunakan pengaman ID operasi. Transaksi yang belum
  pasti tidak dihapus atau dianggap berhasil begitu saja.
- SQL mempertahankan hubungan kategori yang sudah ada. Saat upgrade dari
  046, hubungan lama disalin satu kali ke skema banyak kategori per produk.
  Menjalankan ulang tidak memasukkan kembali produk yang telah dikeluarkan.
- Alur login dan jumlah permintaan data saat membuka menu tetap sama.

JIKA MASIH GAGAL
Kirimkan teks atau screenshot pesan merah yang tampil di dalam pop-up
setelah patch ini. Pesan tersebut kini menunjukkan error sebenarnya, sehingga
penanganannya bisa ditentukan tanpa menebak kondisi server.
Jika tertulis "Kategori sudah berubah", tutup pop-up dan Perbarui stok
sebelum membuka pengaturan kategori lagi.
