MANIAC DUREN — MENU + KERANJANG

PEMASANGAN
Ekstrak seluruh isi ZIP ke root proyek, sejajar folder assets.
Gunakan folder assets yang sudah ada; foto/logo tidak disertakan dalam lampiran.
Halaman menu: /menu/ (hosting dapat menormalkan /menu menjadi /menu/).
Panel kelola: /menu/kelola.html
Jika ada catch-all rewrite Vercel ke index.html, pastikan /menu/* dilayani sebagai file statis sebelum aturan catch-all.

HARGA DAN STOK
Harga berupa angka Rupiah utuh. Contoh: 75000, bukan Rp75.000.
Kosongkan harga untuk menandai Stok Habis; tombol tambah menjadi nonaktif.
Harga 0 adalah harga valid (Rp0), bukan Stok Habis.
Pilih satuan kg, porsi, paket, box atau buah.
Monthong saat ini 75000/kg mengikuti data sebelumnya.
Harga Kupas dan Paket masih kosong, sehingga Stok Habis.
Format menu.json: price berupa number atau null (stok habis).
Draf format harga lama di browser dikonversi saat pertama dimuat.

KERANJANG
Tambah produk, tambah/kurangi jumlah atau hapus item.
Jumlah 1–99 per produk; untuk kg, kenaikan per 1 kg.
Total belum termasuk ongkir; berat akhir dikonfirmasi via WhatsApp.
Keranjang disimpan pada browser, dipulihkan saat halaman dibuka kembali,
dan diperiksa terhadap menu publik terbaru saat halaman dimuat.
Produk yang dihapus atau stok habis dibuang dari keranjang lama.
Checkout membuka pesan WhatsApp berisi rincian pesanan dan total.
Ini permintaan pesanan, bukan pembayaran atau reservasi stok otomatis.

KELOLA DAN PUBLIKASIKAN
Buka /menu/kelola.html, isi produk lalu simpan.
Draf hanya tersimpan di browser Anda, belum terlihat oleh pengunjung.
Klik Unduh menu.json, ganti menu/menu.json di proyek, kemudian deploy.
Panel tidak memiliki akses menulis ke server; pengunjung tidak dapat
mengubah menu publik dengan mengedit draf browsernya sendiri.
Foto unggahan PNG/JPG/WebP maksimal 2 MB disimpan dalam JSON.
Untuk banyak gambar, gunakan file /assets/ agar ukuran JSON tetap ringan.

Git (pemasangan awal):
git status
git add index.html menu/
git commit -m "Add shopping cart and numeric menu prices"
git push

Git (pembaruan menu selanjutnya):
git add menu/menu.json
git commit -m "Update menu prices and stock"
git push

VALIDASI
Sintaks JavaScript dan logika harga, stock, jumlah, total, migrasi draf,
dan ringkasan WhatsApp sudah diuji. Browser visual tidak tersedia dalam
lingkungan pengerjaan. Belum dipublikasikan ke domain.

TAMPILAN MENU BARU
Kartu ringkas 3 kolom desktop, 2 kolom tablet, 1 kolom HP.
Foto di kanan, informasi di kiri, tombol jumlah langsung di kartu.
Bar bawah muncul setelah produk masuk keranjang dan membuka popup pesanan.
Catatan produk ikut tersimpan di browser dan dikirim melalui WhatsApp.
Tombol minus pada jumlah 1 menghapus produk dari keranjang.
Stok Habis menampilkan gambar grayscale dan tombol nonaktif.
Tidak ada harga coret/promo palsu: harga sesuai menu.json.

Di panel kelola tersedia Kelompok menu untuk mengelompokkan produk.
Jika kosong, produk ditampilkan di kelompok Pilihan Durian.
Kelompok tidak mengubah label kategori produk yang sudah ada.
Foto menggunakan folder assets lama yang tidak ada dalam lampiran.
