MANIAC DUREN — PATCH 056: PANJANG STRUK MENGIKUTI ISI

Pasang di atas patch 055. ZIP hanya berisi file baru/berubah.
Tidak memerlukan SQL atau perubahan data transaksi.

PENYEBAB
Kode sebelumnya mengatur lebar struk, tetapi belum mengatur tinggi halaman.
Akibatnya isi struk selesai lebih awal daripada panjang kertas yang dipakai
browser/printer. Pada gambar juga terlihat header/footer browser.

PERBAIKAN
- Tombol Cetak struk dan cetak otomatis memakai dokumen cetak lokal khusus.
- Hanya isi struk yang disalin: tanpa sidebar, tinggi dialog, dan kontrol POS.
- Lebar tetap 80 mm, sesuai format sebelumnya. Tinggi diukur dari isi pada
  lebar tersebut, lalu dijadikan ukuran halaman dengan margin halaman 0.
- Padding isi 3 mm di atas/samping, 2 mm di bawah, ditambah toleransi 1 mm
  untuk pembulatan cetak. Tidak ada tinggi minimum sepanjang halaman.
- Font bawaan, tanpa unduhan font, permintaan database, atau pustaka baru.
- Struk panjang tidak dipotong oleh batas tinggi buatan.
- Dokumen cetak tetap tersedia selama pratinjau; diganti saat cetak berikutnya.
  Maksimal satu dokumen disimpan di memori, tanpa cache/data persisten baru.
- Cetak ulang tidak membuat transaksi atau mengurangi stok lagi.
- Gagal menyiapkan cetak memberi pesan; transaksi tersimpan tetap aman.
- Rantai modul yang berubah memakai versi 056 untuk pembaruan cache.

PASANG DAN COBA
1. Ekstrak ZIP ke root proyek dan timpa file yang sama.
2. Commit/push, tunggu deployment selesai, lalu Ctrl+Shift+R pada POS.
3. Buka transaksi tersimpan > Detail / struk > Cetak struk.
   Gunakan tombol Cetak struk di aplikasi untuk ukuran halaman dinamis.
   Ctrl+P pada halaman utama masih mengikuti stylesheet umum POS.
4. Pilih printer/kertas thermal 80 mm, margin None/Tidak ada, skala 100%,
   dan nonaktifkan Headers and footers/Header dan footer bila tersedia.
5. Periksa pratinjau: isi sampai Kembalian/Alasan void harus terlihat, dengan
   sedikit ruang aman di bawah. Tidak perlu membuat pembayaran baru.

BATASAN PRINTER
Ukuran halaman CSS merupakan permintaan kepada browser. Jika driver hanya
menyediakan panjang kertas tetap, hasil fisik masih dapat mengikuti panjang
tersebut. Gunakan opsi roll/continuous/auto length bila driver menyediakannya.
Tidak ada perintah potong kertas ESC/POS di patch ini.
