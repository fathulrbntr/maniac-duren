MANIAC DUREN — PATCH 052: HAPUS KATEGORI POS

Paket file baru/berubah di atas patch 051 yang sudah dikonfirmasi benar.

PEMASANGAN
1. Ekstrak isi ZIP ke root proyek, lalu timpa file lama.
2. Buka database/pos-menu-categories.sql di VS Code, Ctrl+A lalu Ctrl+C.
3. Supabase → SQL Editor → New query. Tempel SELURUH isi file dan Run.
   Pastikan baris terakhir commit; ikut dijalankan.
   SQL ini menambahkan dukungan hapus kategori. Aman dijalankan ulang;
   produk, stok, transaksi, dan hubungan kategori lain tetap tersimpan.
4. Commit/push, tunggu deploy selesai, lalu muat ulang POS (Ctrl+Shift+R).

CARA PAKAI
Kelola kategori & produk → Hapus kategori pada baris kategori yang dipilih
→ periksa nama dan jumlah produk → Hapus kategori untuk konfirmasi.

Tombol Hapus kategori berada di samping Kelola produk. Kembali ke daftar
kategori membatalkan konfirmasi. Tidak ada penghapusan sebelum konfirmasi.

PERILAKU
- Kategori dihapus dari daftar dan filter POS di semua outlet.
- Produk tetap ada di Semua, Master Barang, dan kategori lainnya.
- Kategori boleh dihapus ketika kosong atau masih berisi produk.
- Semua adalah tampilan seluruh produk jual dan tidak memiliki tombol hapus.
- Jika filter yang sedang aktif dihapus, POS kembali ke Semua. Kata
  pencarian, keranjang, catatan pesanan, dan form buah dipertahankan.
- Jika seluruh kategori dihapus, Semua tetap tersedia dan kategori baru
  tetap dapat dibuat. Kategori bawaan yang dihapus tidak dibuat ulang.
- Hak akses sama dengan pengelolaan Master Barang. Server tetap memeriksa
  hak akses, versi kategori, dan ID operasi untuk kirim ulang.
- Jika kategori berubah di perangkat lain sebelum dikonfirmasi, server
  menolak penghapusan dan meminta pembaruan data.
- Pesan kesalahan tetap tampil langsung di pop-up. Kegagalan tidak dianggap
  berhasil dan pengiriman ganda tidak membuat operasi ganda.
