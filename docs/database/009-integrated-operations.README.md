# Migration 009

Migration ini menambahkan role dan permission karyawan, absensi, sortir, biaya per penerimaan, jejak stok, pesanan dessert, pemakaian resep saat kitchen mulai membuat, waste bahan, dan laporan laba kotor.

Jalankan `009-integrated-operations.sql` satu kali di Supabase setelah database POS versi sebelumnya terpasang. Untuk database baru, gunakan `database/pos.sql` yang sudah memuat migration ini.
